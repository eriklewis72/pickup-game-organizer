# pickup-game-organizer
MVP Scope
This java program will let the organizer create one soccer game with a date, location, and player limit. They can add players, change their RSVP status, and view the confirmed roster and open spots. 

Future Plans
If time allows, I may add file saving and reloading, support for other sports, a desktop interface, and team generation based on positions and/or skill levels. 

Tech Stack
Language: Java
Libraries and tools: Java’s standard library only. Everything that I will be using is included in the Java standard library. 
Data storage: MVP will keep game and RSVP information in memory while the program is running. In V2.0 I will be saving games to a file. 
External data sources: None.
Interface: MVP is the terminal. V2.0 will be desktop app using Swing.
